# Belajar JavaScript

Latihan kecil seputar scope dan pemanggilan fungsi di JavaScript.

- `index.html` - halaman uji yang memuat `main.js`
- `main.js` - contoh `outer()` dan `inner()` beserta urutan `console.log`
- `.vscode/launch.json` - konfigurasi debug

## Menjalankan

Buka `index.html` di browser, lalu lihat console.
